# Release and operations drafts — Chao Garden MMO

This packet was generated by Vibe and merged as documentation in server commit
`b525d8b` (PR #1). It contains proposed release checklists and procedures. It is
not evidence that an app-store release, durable AFK training service, installed
Android widget, account deletion, moderation tools or push notifications exist.
Unchecked boxes, placeholder contacts, proposed ratings and signature tables
are not completed reviews or approvals.

Use the server-repository coordination layer for current implementation and
work ownership:

- [Coordination board](../coordination/BOARD.md): verified activity, local
  evidence, planned features, dependencies and merge order.
- [Complete workstream briefs](../coordination/WORKSTREAMS.md): twelve scoped
  implementation streams and the original integration/release role.
- [Protocol coordination](../coordination/PROTOCOL.md): proposed accounts,
  pairing, ownership, migration and atomic-save constraints; not a shipped v2
  protocol.

The user's native-asset development scope remains in place: Sonic Adventure 2 +
BATTLE imports and supplied GBA source investigations stay local/ignored,
while tooling/source/tests/docs are published. The all-original store concept,
alternate names and review/sign-off forms in this packet are unapproved draft
proposals; they do not authorize replacing that scope or establish distribution
rights, legal conclusions, completed policies or store eligibility.

## Current local implementation versus planned release

- **Rust server:** custom authority in `src/service.rs`, `src/game.rs`,
  `src/phone.rs`, `src/watch.rs` and `src/activities.rs`. Five adapted Tiny
  minigames and persistent resident Watch are implemented/tested locally.
  [PHONE.md](../../PHONE.md), [WATCH.md](../../WATCH.md) and
  [ACTIVITIES.md](../../ACTIVITIES.md) describe their limits.
- **Training:** `crates/tiny-garden-core` includes a tested standalone
  TrainingLedger. Durable live job start/cancel/settle, app controls and device
  ownership integration remain planned work; `src/phone.rs` hosts minigames.
- **Client:** browser desktop/Tiny clients use the same canonical local profile.
  The retained Node reference supports comparison/fallback but does not host
  Rust Tiny games. Production pairing, exclusive device leases and the proposed
  authentication migration are not established by this packet.
- **Widget:** a browser layout/snapshot preview exists. An installed Android
  widget, OS-managed refresh, secure revocable pairing and quick server-validated
  pet/care are planned. The full Tiny Garden app owns minigames and AFK training
  controls. No native APK/widget acceptance is claimed.
- **Operations:** public capacity, deployment, account deletion, moderation,
  refunds/admin tooling and push campaigns need implementation-specific proof.
  Their procedure drafts must not be presented as live capabilities.
